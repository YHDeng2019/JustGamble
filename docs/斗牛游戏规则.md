# 斗牛（牛牛）游戏规则文档

> 本文档用于指导 AI / 开发者实现"斗牛"扑克游戏的核心逻辑，包含规则说明、牌型定义、比牌逻辑和伪代码示例。

---

## 1. 基本设置

- 使用一副标准扑克牌（去掉大小王，共 52 张），不计花色，只计点数。
- 玩家人数：通常 2-10 人，常见为 4-6 人模式。
- 每位玩家发 5 张牌。
- 常见玩法为"庄家模式"：一名玩家担任庄家，其余玩家分别与庄家比牌大小，按倍数结算下注。

## 2. 牌面点数对照

| 牌面 | 点数 |
|------|------|
| A | 1 |
| 2-10 | 对应数字 |
| J | 10 |
| Q | 10 |
| K | 10 |

## 3. 核心算法：找"牛"

从手中 5 张牌里，找出 3 张牌，使其点数之和能被 10 整除（即和为 10、20 或 30）。这 3 张牌称为"牛"，剩下 2 张牌的点数之和取个位数，即为"牛几"。

### 计算步骤

1. 列出 5 张牌中所有 3 张牌的组合（共 C(5,3) = 10 种）。
2. 检查每种组合的点数之和是否能被 10 整除。
3. 若存在符合条件的组合，剩余 2 张牌点数之和的个位数即为"牛几"。
4. 若所有组合都不满足，则判定为"没牛"（也称"葳"）。

### ⚠️ 关键边界条件（必须在开发前明确，否则极易出 bug）

1. **多组合冲突**：如果 5 张牌存在多种"凑出 10 倍数"的 3 张牌组合方式，理论上可能算出不同的"牛几"。需要明确规则，常见做法是：**取所有可能组合中最大的牛值**。
2. **牛十的处理**：当剩余两张牌点数和为 10 或 20（个位数为 0）时，有两种常见处理方式，需二选一并写入文档：
   - 方式 A：视为"没牛"（最小牌型）。
   - 方式 B：单独算作一种特殊牌型"牛十/老牛"，地位通常高于牛九。
   - **建议**：实现时做成可配置项（如 `treatNiuTenAsSpecial: true/false`）。
3. **特殊牌型优先判定**：炸弹、五小牛、五花牛等特殊牌型，必须在判断"普通牛几"之前先行判定，一旦满足特殊牌型条件，直接按特殊牌型处理，不再走普通牛几逻辑。

## 4. 牌型大小排序（从大到小）

| 排名 | 牌型 | 说明 |
|------|------|------|
| 1 | 五花牛 | 5 张牌全部为 J/Q/K（即点数都为10）。规则差异较大，可设为可选项 |
| 2 | 炸弹 | 5 张牌中有 4 张点数相同 |
| 3 | 五小牛 | 5 张牌点数均在 2-8 之间，且总和能被 10 整除 |
| 4 | 牛九 | 剩余两张牌点数和个位数为 9 |
| 5 | 牛八 | 个位数为 8 |
| 6 | 牛七 | 个位数为 7 |
| 7 | 牛六 | 个位数为 6 |
| 8 | 牛五 | 个位数为 5 |
| 9 | 牛四 | 个位数为 4 |
| 10 | 牛三 | 个位数为 3 |
| 11 | 牛二 | 个位数为 2 |
| 12 | 牛一 | 个位数为 1 |
| 13 | 没牛 | 找不到任何 3 张牌之和为 10 的倍数 |

> 注：炸弹、五小牛、五花牛属于"特殊牌型"，各地规则对其启用与否、排序高低差异较大。建议实现为**可配置规则集**，方便后续调整。

## 5. 比牌规则

1. 所有玩家亮牌后，按上表牌型大小从大到小排序，决出胜负。
2. **庄家模式**：庄家分别与每位闲家比较，牛大的一方赢，牛小的一方输，按对应倍数结算下注金额。
3. **同牌型比较**：当两人牛型相同（如都是"牛三"）时，常见的二级比较方式有两种，建议二选一并写入文档：
   - 方式 A：比较 5 张牌中单张最大点数。
   - 方式 B：比较用于"凑牛"的 3 张牌中的最大单张点数。
4. **完全打平**：若按比较规则仍无法分出胜负，可约定庄家胜，或直接判定为平局（不结算下注）。

## 6. 下注倍数参考（可选功能）

若游戏需要计分/下注系统，常见倍数设置如下（仅供参考，建议做成可调参数）：

| 牌型 | 倍数 |
|------|------|
| 没牛 / 牛一～牛九 | 1 倍 |
| 五小牛 | 3 倍 |
| 炸弹 | 4 倍 |
| 五花牛 | 5 倍 |

## 7. 伪代码示例

```
输入：5张牌的点数列表 cards = [c1, c2, c3, c4, c5]

函数 计算牌型(cards):
    # 第一步：判断特殊牌型（优先级最高）
    if 是炸弹(cards):
        return "炸弹"
    if 是五花牛(cards):
        return "五花牛"
    if 是五小牛(cards):
        return "五小牛"

    # 第二步：遍历所有3张牌组合，寻找牛几
    所有组合 = combinations(cards, 3)  # 共10种
    候选牛值列表 = []

    for 组合 in 所有组合:
        if sum(组合) % 10 == 0:
            剩余两张 = cards 中除去这3张的另外2张
            牛值 = sum(剩余两张) % 10
            候选牛值列表.append(牛值)

    if 候选牛值列表 为空:
        return "没牛"
    else:
        最大牛值 = max(候选牛值列表)
        if 最大牛值 == 0:
            # 根据约定的处理方式选择一种：
            # return "没牛"          # 方式A
            # return "牛十/老牛"      # 方式B
            pass
        return f"牛{最大牛值}"


函数 比较牌型(玩家A牌型, 玩家B牌型):
    # 按牌型大小表排序后比较优先级
    if 优先级(玩家A牌型) != 优先级(玩家B牌型):
        return 优先级更高的一方
    else:
        # 同牌型，进入二级比较
        return 比较单张最大点数(玩家A, 玩家B)  # 或按约定规则比较凑牛的3张
```

## 8. 开发前必须确认的三个关键问题

在交给 AI 实现之前，建议先明确以下三点，这是各地版本规则差异最大、也最容易写错的地方：

1. **牛十怎么处理**？（归入"没牛" 还是单独成为最大特殊牌型）
2. **是否启用特殊牌型**？（炸弹 / 五小牛 / 五花牛是否需要实现，排序如何）
3. **同牌型打平规则**？（比较单张最大点数 / 比较凑牛的3张牌 / 直接判庄家赢）
