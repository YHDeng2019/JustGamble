# 斗牛（牛牛）游戏规则文档

> 本文档用于指导 AI / 开发者实现"斗牛"扑克游戏的核心逻辑，包含规则说明、牌型定义、比牌逻辑、底池机制和结算流程。

---

## 1. 基本设置

- 使用一副标准扑克牌（去掉大小王，共 52 张），不计花色，只计点数。
- 玩家人数：通常 2-10 人，常见为 4-6 人模式。
- 每位玩家发 5 张牌。
- **初始筹码**：每位玩家 1000 筹码。
- **庄家底池**：庄家上任时需一次性放入 200 筹码作为底池（若手上筹码不足 200 则无法当庄，会被跳过）。
- **基础下注**：闲家基础下注 100 筹码（可自由调整）。

## 2. 牌面点数对照

| 牌面 | 点数 |
|------|------|
| A | 1 |
| 2-10 | 对应数字 |
| J | 10 |
| Q | 10 |
| K | 10 |

## 3. 核心算法：找"牛"

从手中 5 张牌里，找出 3 张牌，使其点数之和能被 10 整除（即和为 10、20 或 30）。这 3 张牌称为"牛"，剩下 2 张牌的点数之和取个位数，即为"牛几"。

### 计算步骤

1. 列出 5 张牌中所有 3 张牌的组合（共 C(5,3) = 10 种）。
2. 检查每种组合的点数之和是否能被 10 整除。
3. 若存在符合条件的组合，剩余 2 张牌点数之和的个位数即为"牛几"。
4. 若剩余两张牌点数之和也是 10 的倍数（个位为 0），则为"牛牛"（最高普通牌型）。
5. 若所有组合都不满足，则判定为"没牛"（也称"葳"）。

### 举例

- 牌面：3、7、8、10、K（点数 3+7+8+10+10）
  - 3+7+10=20（10的倍数），剩余 8+10=18，个位 8 → **牛八**
  - 7+8+10=25（不是10的倍数）
  - 3+8+10=21（不是10的倍数）
  - 取最大牛值 → 牛八

- 牌面：5、5、J、Q、K（点数 5+5+10+10+10）
  - 5+5+10=20（10的倍数），剩余 10+10=20，个位 0 → **牛牛**

### ⚠️ 关键边界条件

1. **多组合冲突**：如果 5 张牌存在多种"凑出 10 倍数"的 3 张牌组合方式，取所有可能组合中**最大的牛值**。
2. **牛十/牛牛的处理**：当剩余两张牌点数和为 10 或 20（个位数为 0）时，视为**牛牛**（地位高于牛九，低于特殊牌型）。
3. **特殊牌型优先判定**：炸弹、五小牛、五花牛等特殊牌型，必须在判断"普通牛几"之前先行判定，一旦满足特殊牌型条件，直接按特殊牌型处理，不再走普通牛几逻辑。

## 4. 牌型大小排序（从大到小）

| 排名 | 牌型 | 说明 | 倍数 |
|------|------|------|------|
| 1 | 五花牛（金花牛） | 5 张牌全部为 J/Q/K（即点数都为10） | ×5 |
| 2 | 炸弹 | 5 张牌中有 4 张点数相同 | ×5 |
| 3 | 五小牛 | 5 张牌点数均在 1-5 之间，且总和能被 10 整除 | ×5 |
| 4 | 牛牛 | 剩余两张牌点数和为 10 的倍数（个位为 0） | ×3 |
| 5 | 牛九 | 剩余两张牌点数和个位数为 9 | ×2 |
| 6 | 牛八 | 个位数为 8 | ×2 |
| 7 | 牛七 | 个位数为 7 | ×2 |
| 8 | 牛六 | 个位数为 6 | ×1 |
| 9 | 牛五 | 个位数为 5 | ×1 |
| 10 | 牛四 | 个位数为 4 | ×1 |
| 11 | 牛三 | 个位数为 3 | ×1 |
| 12 | 牛二 | 个位数为 2 | ×1 |
| 13 | 牛一 | 个位数为 1 | ×1 |
| 14 | 没牛 | 找不到任何 3 张牌之和为 10 的倍数 | ×1 |

## 5. 倍数规则

| 牌型 | 倍数 | 说明 |
|------|------|------|
| 没牛 / 牛一～牛六 | ×1 | 普通牌型 |
| 牛七 / 牛八 / 牛九 | ×2 | 中等牌型翻倍 |
| 牛牛 | ×3 | 高级牌型三倍 |
| 五小牛 / 炸弹 / 五花牛 | ×5 | 特殊牌型五倍，**无论输赢都要翻倍** |

### 倍数计算方式

结算时，取**双方牌型倍数的最大值**作为本局倍数：

```
实际倍数 = max(闲家倍数, 庄家倍数)
结算金额 = 下注金额 × 实际倍数
```

**举例：**
- 闲家1是牛七（×2，下注200），闲家2是牛三（×1，下注100），庄家是牛六（×1）
  - 闲家1赢：max(2,1)=2，从底池拿走 200×2=400
  - 闲家2输：max(1,1)=1，放入底池 100×1=100
- 庄家是牛牛（×3），其他人都没庄家大
  - 所有闲家输：放入下注金额×3 的筹码进底池
- 闲家是五小牛（×5），无论输赢都按 ×5 结算

## 6. 底池机制（核心）

### 底池的来源与去向

1. **庄家入池**：庄家上任时一次性放入 200 筹码进入底池。
2. **底池持久化**：底池在整个当庄期间**跨局保持**，不会每局清零。
3. **闲家只能从底池瓜分筹码**：赢的闲家从底池拿钱，输的闲家往底池放钱。
4. **庄家不直接参与每局结算**：庄家的盈亏体现在底池的增减上，当庄结束时一次性结算。

### 庄家退出方式（两种）

1. **流庄**：当底池被瓜分到不足 20 筹码时，自动流庄。庄家带走剩余底池，轮换到下一位有资格的玩家。
2. **主动转庄**：当庄满 3 局后，庄家可主动选择跳过当庄，并**带走所有底池筹码**。

### 庄家资格

- 筹码 ≥ 200 才有资格当庄。
- 若所有玩家筹码都不足 200，游戏结束。

## 7. 比牌规则

1. 所有闲家分别与庄家比较（闲家之间不比较）。
2. 牛大的一方赢，牛小的一方输，按对应倍数结算下注金额。
3. **同牌型比较**：比较 5 张牌中单张最大点数（A 最大，K > Q > J > 10 > ... > 2）。
4. **完全打平**：若按比较规则仍无法分出胜负，判定为平局（不结算）。

## 8. 结算流程（重要）

每局结算按以下顺序进行：

### 步骤一：输的闲家先放入筹码进入底池

- 所有输的闲家依次将"下注 × 倍数"的筹码放入底池。
- 若闲家筹码不足，则放入其全部剩余筹码。

### 步骤二：赢的闲家再从底池拿走胜利的筹码

- 赢的闲家按**牌面从大到小**依次从底池拿钱。
- 拿取金额 = 下注 × 倍数。
- **若轮到自己时底池已被拿完或不足，则只能拿到剩余部分**（拿不足也没办法）。

### 步骤三：底池剩余归庄家（跨局保持）

- 本局结算后，底池剩余筹码**保留在底池中**，供下一局使用。
- 庄家不每局取走底池，而是当庄结束时一次性带走。

### 结算动画

每局结算时，按上述顺序播放筹码飞行动画：
1. 输家筹码从自己座位飞向公共底池。
2. 赢家筹码从公共底池飞向自己座位。
3. 按结算顺序依次播放（输家先，赢家按牌面大到小）。

## 9. 伪代码示例

```
输入：5张牌的点数列表 cards = [c1, c2, c3, c4, c5]

函数 计算牌型(cards):
    # 第一步：判断特殊牌型（优先级最高）
    if 是五花牛(cards):       return "五花牛"   # ×5
    if 是炸弹(cards):         return "炸弹"     # ×5
    if 是五小牛(cards):       return "五小牛"   # ×5

    # 第二步：遍历所有3张牌组合，寻找牛几
    所有组合 = combinations(cards, 3)  # 共10种
    候选牛值列表 = []

    for 组合 in 所有组合:
        if sum(组合) % 10 == 0:
            剩余两张 = cards 中除去这3张的另外2张
            牛值 = sum(剩余两张) % 10
            if 牛值 == 0:
                候选牛值列表.append(牛牛)  # 个位0 = 牛牛
            else:
                候选牛值列表.append(牛值)

    if 候选牛值列表 为空:
        return "没牛"
    else:
        return max(候选牛值列表)


函数 结算(bankerIndex, handResults, bets, chips, currentPool):
    pool = currentPool
    losers = []
    winners = []

    for i in 闲家:
        cmp = 比较牌型(闲家i, 庄家)
        mult = max(倍数[闲家i牌型], 倍数[庄家牌型])
        amount = bets[i] * mult

        if cmp < 0:  # 闲家输
            losers.append({i, min(amount, chips[i])})
        elif cmp > 0:  # 闲家赢
            winners.append({i, amount, rank: 闲家i牌型})

    # 步骤一：输家先放入底池
    for loser in losers:
        pool += loser.amount
        chips[loser.i] -= loser.amount

    # 步骤二：赢家按牌面大到小依次取
    winners.sort(by rank desc)
    for winner in winners:
        take = min(winner.amount, pool)
        pool -= take
        chips[winner.i] += take

    # 步骤三：底池剩余保持，不归庄家（跨局持久化）
    return {chips, pool_remaining: pool}


函数 检查流庄(pool, rounds):
    if pool < 20:
        return 流庄  # 庄家带走剩余底池，轮换
    if rounds >= 3:
        return 可选转庄  # 庄家可选择带走底池
    return 继续
```
